# SEO archive and past-date checklist

- [ ] Confirm the route has no future departures in the CMS schedule as of the review date.
- [ ] Remove expired availability language and stale date/price claims from rendered content.
- [ ] Keep evergreen route description and useful travel information if the route remains a real offer.
- [ ] Show a clear next-date/contact state; do not replace the page with a generic loading state.
- [ ] Keep the URL indexable only when it still satisfies a search intent and has useful content.
- [ ] If the route is permanently discontinued, choose one intentional action: relevant 301, real 404/410, or a clearly marked archive page. Record the decision.
- [ ] Update internal links and sitemap according to the publication status.
- [ ] Re-run production smoke checks and inspect the rendered HTML.

The default policy is not to mass-noindex pages merely because dates are temporarily empty. This decision must be validated against GSC/Yandex impressions and the product owner’s catalogue policy.
