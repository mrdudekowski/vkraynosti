# Расписание туров — инструкция для менеджера

> PDF-версия: `[TOUR_DATA_MANAGER_GUIDE.pdf](./TOUR_DATA_MANAGER_GUIDE.pdf)` (обновить: `npm run generate:manager-guide-pdf`)

Google Таблица «Шаблон для календаря» + меню **Вкрайности** вверху справа (если меню не видно целиком — нажмите **💬**).

Краткая шпаргалка также на листе `**_Инструкция`** в таблице.

## 🌲 Добавить новый тур в сезон

1. Откройте лист **Туры_Зима** / **Туры_Весна** / **Туры_Лето** / **Туры_Осень** (нужный сезон).
2. Найдите первую пустую строку в колонках **A–D** (ниже существующих туров).
3. Заполните:


| Колонка | Заголовок       | Что вводить                                                                       |
| ------- | --------------- | --------------------------------------------------------------------------------- |
| **A**   | ID тура         | `summer-13`, `spring-3` … латиница, формат **сезон-номер** (`winter-1`, `fall-5`) |
| **B**   | Название        | Название тура для сайта и списка                                                  |
| **C**   | Цена ₽          | Число в рублях или **пусто** («по запросу»)                                       |
| **D**   | Тип тура        | `однодневный` или `многодневный` (из списка в ячейке)                             |
| **F**   | Статус на сайте | `активен` / `в разработке` / `скрыт` (см. ниже)                                   |


1. Колонку **E** («Подпись списка») **не трогайте** — заполняется автоматически (`Название | summer-3`).
2. Тур появится в выпадающем списке **«Тур»** (колонка C) на листе **Расписание_*** того же сезона.

Если списка нет: **Вкрайности → Настроить таблицу (всё)** (или **Настроить списки туров (колонка C)**).

### Статус на сайте (колонка F)


| Значение         | Что происходит                                                  |
| ---------------- | --------------------------------------------------------------- |
| **активен**      | Тур и выезды публикуются на сайт (после меню «Обновить …»)      |
| **в разработке** | Карточка тура на сайте есть, **выезды в календарь не попадают** |
| **скрыт**        | Тур и выезды **не показываются** на сайте                       |
| *(пусто)*        | **Черновик** — на сайт не уходит                                |

## 📅 Добавить выезд в расписание

1. Лист **Расписание_Зима** / **Расписание_Весна** / **Расписание_Лето** / **Расписание_Осень** того же сезона.
2. Заполните **обязательные** поля (без них выезд не попадёт на сайт):


| Колонка | Заголовок   | Обязательно                                                                |
| ------- | ----------- | -------------------------------------------------------------------------- |
| **A**   | Дата        | ✅ клик по ячейке → иконка календаря справа (даты только в пределах сезона) |
| **C**   | Тур         | ✅ выбор из списка каталога                                                 |
| **H**   | Статус      | ✅ `запланирован` / `набор открыт` / `мест нет` / `отменён` / `завершился`  |
| **G**   | Места       | по желанию — число или пусто                                               |
| **I**   | Комментарий | по желанию                                                                 |


1. Колонки **B**, **D**, **E**, **F** **не редактируйте** — подставятся сами (день недели, ID тура, тип, цена из каталога).
2. Пустой **H** = черновик выезда (на сайт не уходит).

### Публикация на сайт

Автообновления **нет**. После правок в таблице:

- **Вкрайности → Обновить туры** — только каталог;
- **Вкрайности → Обновить расписание** — только выезды (нужен уже опубликованный каталог);
- **Вкрайности → Обновить всё** — сначала туры, затем расписание (рекомендуется).

Данные уходят в облако; сайт подхватывает их **без пересборки**, обычно в течение минуты.

## ❌ Проверка таблицы

**Вкрайности → Проверить таблицу** — отчёт на листе `**_Проверка`**.


| Уровень                            | Значение                                                                                                                                                         |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Предупреждение** «…нет на сайте» | Тур есть в таблице, но ещё **не добавлен в каталог сайта** (`toursData.ts`). Расписание сохранится; карточки на сайте не будет, пока разработчик не добавит тур. |
| **Предупреждение** «Дубликат»      | Один и тот же тур на одну дату встречается дважды.                                                                                                               |
| **Ошибка**                         | Нет даты при выбранном туре, неверный статус, выезд для **скрытого** тура и т.п.                                                                                 |


---

## 🧟‍♂️ Чего нельзя делать

- **Редактировать список «Тур» через карандаш в ячейке** — список отвяжется от каталога, новые туры не появятся.
- **Менять формулы в E на «Туры_*»** — сломается dropdown.
- **Менять B, D, E, F на «Расписание_*»** — сломается экспорт.
- **Дублировать один тур на одну дату.**
- **Менять ID тура (колонка A)** после того, как тур уже есть в расписании.

---

## 💡 Ошибка «Синтаксическая ошибка в формуле» (#ERROR!)

1. **Вкрайности → Исправить формулы (#ERROR!)**
  или **Настроить таблицу (всё)**.
2. Проверьте **Файл → Настройки**: локаль **Россия**.
3. Если ошибка осталась — напишите разработчику сайта (нужен доступ к таблице).
