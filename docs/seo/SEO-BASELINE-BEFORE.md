# SEO baseline до оптимизации

Дата: 2026-09-03. Это baseline кода и публичного наблюдения; данных Search Console/Yandex Webmaster в репозитории нет.

## Подтверждено публичным поиском

- Для `site:vkraynosti.ru` главная показывала title `Вкрайности`, а в описании встречались `Сверяем список «что взять с собой»`, `# Что-то пошло не так` и `Произошла ошибка. Попробуйте обновить страницу.`
- В выдаче присутствовал корректный результат активного маршрута `/tours/summer/robinzonada-primorskoe-bali/` с содержательным текстом.
- При прямом чтении публичного URL через использованный PowerShell-клиент TLS не установился; это не доказательство поломки production и требует проверки независимым HTTP-клиентом/браузером.

## Подтверждено кодом до фиксов

- Приложение было SPA, поэтому initial HTML мог не содержать содержательного body до выполнения JavaScript.
- SEO-слой уже имел canonical, robots, sitemap и policy по статусам, но не имел отдельного локального гейта, связывающего sitemap с реально созданными route HTML.
- Сезонные data-SSG страницы не добавляли JSON-LD.
- OG-проверка падала при отсутствии бинарника `ffmpeg-static`; fallback мог быть WebP, а не JPEG 1200×630.

## Непроверенные гипотезы

Нельзя по одному сниппету утверждать, какой именно crawler snapshot был выбран Google/Yandex и был ли production уже обновлён. Нужны URL Inspection, server logs и HTTP-заголовки текущего production.
